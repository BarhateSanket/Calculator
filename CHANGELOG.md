## [1.0.0] - 2025-11-12

### Added
- Initial release of Simple Calculator
- Basic arithmetic operations: addition (+), subtraction (-), multiplication (*), division (/), and modulo (%)
- AC (All Clear) button to reset calculator state
- DEL (Delete) button to remove last entered character
- Real-time input display with placeholder "0"
- Dark-themed user interface with responsive design
- Error handling for invalid expressions
- Support for decimal numbers (.)
- Double zero (00) button for faster input
- Operator buttons with distinct styling
- Equal button (=) to evaluate expressions

### Technical
- Built with vanilla HTML5, CSS3, and JavaScript (ES6)
- No external dependencies or frameworks
- Event-driven architecture for button interactions
- Responsive layout for all screen sizes
- Preview image added for documentation
